# Contributing to Project Hydra

Thank you for your interest in contributing to Project Hydra!

## Guidelines

- Read CODE_OF_CONDUCT.md before contributing.
- Open an issue before starting any major feature.
- Fork the repo and submit a PR to **main**.
- Follow code style and include relevant tests.
- Run `./tools/format.sh` (or `cargo fmt`, `./gradlew ktlintFormat`) before committing.
- For security issues, DO NOT create a public issue — contact maintainers privately.
